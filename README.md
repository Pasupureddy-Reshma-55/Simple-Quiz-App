# 📝 Simple Quiz App

## 📌 About the Project

The **Simple Quiz App** is an interactive web application developed using HTML, CSS, and JavaScript. It allows users to participate in quizzes, answer multiple-choice questions, and test their knowledge in a simple and enjoyable way.

The application provides a clean and user-friendly interface that makes learning more interesting. Users can select answers, move through questions, and view their quiz results.

## ✨ Features

- Simple and user-friendly interface.
- Interactive multiple-choice questions.
- Easy question navigation.
- Answer selection functionality.
- Automatic score calculation.
- Displays quiz results.
- Responsive and attractive design.
- Smooth user interaction.

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the application.
- **CSS3** – Used to design and style the user interface.
- **JavaScript** – Used to implement quiz functionality and interactive features.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `Simple Quiz.html` file.
4. Open the HTML file in your web browser.
5. Start answering the quiz questions.
6. Complete the quiz and check your score.
